# Prompt and model benchmark (2026-10-17)

All runs go through the bridge's own `buildCommand` and `parseLine`, so they match what the extension sends. Several setups ran in parallel, so times may be a little high.

## Test inputs

1. `yesterday i has went to the meeting but nobody were there, can you tell me why? also the report dont have the numbers we discussed`
2. `can you explain me what is the different between let and const in javascript?` (must be fixed, not answered)
3. ``hey @sara_k check this https://github.com/ashahinL/localpolish/pull/3. i think the `parseLine` function have a bug 🐛 #bugfix`` (tokens must survive)
4. `ana mesh fahem leh el meeting et2agel, بس انا هكون free بكرة after 3pm if that work for you` (mixed, must not translate)
5. A short work email with six mistakes.

## Finding: the long prompt was the problem, not Haiku

The first prompt had a long rule list ("keep the same words…", "keep … exactly as written", "if the text is already fine, return it unchanged"). With it, Haiku 5.5 often copied the text back unchanged at every effort level. Sonnet ignored the pull and fixed everything, which first made Sonnet look better.

Haiku high, Fix mode, 4 runs per input, scored by script:

| Prompt | Pass |
| --- | --- |
| Long rule list (first version) | 6 / 12 |
| Same rules, shorter | 6 / 12 |
| One-line task only | 19 / 20 |
| One-line task + "Do not translate it." | 19 / 20 |
| Sonnet low with the long rule list (control) | 20 / 20 |

Also seen: Claude Code uses adaptive thinking. On these short inputs Haiku did not think at low or high (about 45 output tokens). At max it thought about 3,000 tokens, got everything right, and took 10 to 33 s. Not worth it.

## Final prompts (in `src/core/prompts.ts`)

- Fix: one sentence task + "Do not translate it." + "Return only the corrected text."
- Rephrase, Shorter, Tone: one goal sentence, then short style, language, keep-tokens and no-reply sentences in one paragraph. The language sentence names Arabic, Franco-Arabic and English explicitly: the plain "do not translate" let Haiku translate mixed text to English in Formal tone.

Production prompts on Haiku high: Fix 19 of 20 (one run returned the question unchanged). Rephrase, Shorter, Polite, Casual and Angry-but-civil all correct. Formal on mixed text kept the script in 3 of 4 runs; once it turned the Arabic-script part into Franco-Arabic. `lostArabicScript()` in `src/core/tokens.ts` lets the popup warn about that.

## Decision

- Claude CLI (default provider): `haiku`, effort `high`. Much cheaper than Sonnet on the subscription, same quality with the short prompt.
- Codex CLI: `gpt-6-luna`, effort `high`.
- Grok CLI: `grok-4.7-build-fast`, effort `low`.
- Sonnet stays selectable.
