# Extension icon

A dark ink (#18213A) fountain-pen nib on a rounded-square highlighter-yellow (#FFE45C) tile. Drawn by hand as SVG. The shape was picked by the user on 2026-10-18; the colors changed to the 1.5.0 look on 2026-10-24.

- `icon.svg`: the full design with a small sparkle near the tip. Used for 48 and 128.
- `icon-medium.svg`: no sparkle, a wider slit through the breather hole to the tip. Used for 32 and the popup header (28 px).
- `icon-small.svg`: a 16-unit grid, pixel-fitted silhouette with a short slit. Used for 16.

`public/icon/{16,32,48,128}.png` were rendered from these with headless Chrome on a transparent background.
